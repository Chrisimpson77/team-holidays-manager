# Team Holidays Manager

A small application for managing team holidays, approvals, and availability.

## Features
- View all holiday requests
- Submit a new holiday request
- Update the status of an existing request
- Filter team leave by status
- Responsive web interface

## Tech Stack
- Node.js
- Express
- Vanilla JavaScript frontend

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.

## Project structure

- `server.js` — Express API and static file server
- `public/` — frontend files
- `package.json` — project scripts and dependencies
